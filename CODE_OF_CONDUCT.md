# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas rather than people,
and do not harass or discriminate. Maintainers may remove comments, commits or
contributions that violate these expectations, and may temporarily or
permanently ban contributors for repeated or severe violations.

## Reporting

Report unacceptable behaviour privately to the maintainer through GitHub
(<https://github.com/Faycall1l>). Reports are handled confidentially. If the
report concerns the maintainer, use GitHub's abuse reporting flow instead.

## Scope

This applies to project spaces (issues, pull requests, discussions, reviews)
and to public spaces when someone is representing the project.
